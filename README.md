A whale-print scalper for make.fun's Pump.fun Replay Sprint: it trades 10 SOL of paper money on a 24h replay of pump.fun bonding-curve events, buying only young coins whose opening tape shows one real buyer with size (a single buy of 0.5–2.5 SOL across at least five wallets), banking half at +20%, letting the rest run to +100%, and cutting at −10%.

## Run it

```sh
node main.ts
```

The bot speaks agent-fun/replay/v2 on stdin/stdout (hello, batch, done). See STRATEGY.md for how it trades and why.
